# Exchange-Rate-and-Bilateral-Trade-Replication
Replication package for Impact of Exchange Rates on Bilateral Trade: Evidence from Bretton Woods System. The package contains cleaned panels for estimation, Jupyter files to replicate figures and tables and construct clean datasets. 

DATA 

•	TRADHIST_v4.dta: This dataset contains 1.9 million bilateral trade flows and 42,000 observations on total imports and exports for a 188-year period spanning 1827–2014. It is used to contruct a panel of bilateral trade flows among 47 sub saharan African countries between 1963-1982.
•	ERA_Classification_Monthly_1940-2019: A classification dataset developed by Ilzetzki, Reinhart, and Rogoff (2019) that categorizes countries' de facto exchange rate arrangements from 1940 to 2019 using monthly variations, parallel market data, and active policy indicators. Data is available on 48 sub Saharan countries. 
•	Anchor_monthly_1946-2019: A companion dataset from Ilzetzki, Reinhart, and Rogoff (2019) that systematically classifies the de facto anchor or reference currency for countries and territories globally on a monthly basis from 1946 to 2019. Data is available on 48 sub Saharan countries. 
•	DESTA (version 2.2): A global database mapping preferential trade agreements that covers bilateral and plurilateral treaties signed worldwide from 1948 onward.
